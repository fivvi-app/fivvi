# `src/import/`

The importer of the data import (E015, spec #478), pure functions over text and rows: `parseWorkbook(bytes)` (an `.xlsx`, via `read-excel-file`) and `parseCsvFiles({ clients: text })` give the same `ParsedImport` (sheets with a header and numbered rows; a file over 5 MB, one that unpacks to over 50 MB or with more than 5,000 rows is refused with an `ImportFileError`); `checkImport(parsed, workspace)` checks the `clients` sheet against a read-only `WorkspaceSnapshot` (required columns, no column outside the template, no header twice (an error), a column with data but no header name is reported by its letter and not imported (a warning), `client_key` and email unique, every client has a valid email, `language`, `status` and `trainer_email`) and gives problems with sheet, row, column, type and severity; `planImport` counts the clients to create, reuse (the email of a client of the workspace, F006) and leave out (`inactive`); `describeProblem(problem, locale)` words a problem in the Owner's language (`dataImport.*` in `packages/i18n`). The sheets of later tickets are added to the same functions

Spec: E015 AC3, AC12, AC15

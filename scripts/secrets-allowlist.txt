# Realistic-looking values allowed in test files (scripts/secrets-in-tests.mjs), one entry per line, each with a reason:
#
#   path-glob: exact-value  # why this one has to stay realistic
#
# Unlike scripts/email-allowlist.txt, where `#` starts a comment, the `#` here starts the reason and is required: an entry
# without one fails scripts/check.sh. The path glob matches the file's path (`*` stays inside a directory, `**` crosses
# them) and the value is the string as it is written in the file, without quotes and without spaces. Prefer an obviously
# fake value (`fake-link-token-for-tests`); this list is for a shape that must stay realistic, such as a published test
# vector of a hash function. It is empty: nothing has to.
#
# The guard already leaves these shapes alone, so they need no entry: a UUID, a token of digits only, a slug or constant
# name (`feature-57-hold-a-spot`, `NEXT_PUBLIC_POSTHOG_KEY`) and a token that repeats one short unit (forty `1`s,
# `0123456789abcdef` twice).

# Breach register

The register of personal-data breaches that the processor agreement requires ([art. 6(5)](../legal/verwerkersovereenkomst.md#article-6-data-breaches), [Artikel 6](../legal/verwerkersovereenkomst.md#artikel-6-datalekken)): every breach Fivvi finds in the data it processes for a workspace, including the ones that turn out not to need a notice, with the measures taken. The owner adds a row in step 8 of the [personal-data breach runbook](../engineering/RUNBOOKS.md#2-personal-data-breach), and an incident note in this folder is linked from the row.

**This repository is public: nothing that identifies a gym, a workspace (no slug), a person or a client goes in this file.** An entry holds only the date, an opaque reference (a number the owner keeps in their own records and can map to the workspace) and the category of the breach and of the data, with counts. Never names, email addresses, client details or note content. Rows removed later stay in git history, so write nothing you would need to remove. The owner decides where the real register (with the workspace, the facts and the gym's decisions) lives; the processor agreement (art. 4 and 6(4)) requires that the gym can have it. The register is kept as long as the processor agreement runs.
